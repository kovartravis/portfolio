# Travis Kovar

Personal site for **Travis Kovar**. Production AI engineer. Full-stack when it matters.

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

---

## Features

A single-column, headline-first page built to be read in one scroll on any screen size. No heavy animation, background effects, or interactive widgets standing between the reader and the content.

- **Hero:** Name, one-line positioning, and a short summary.
- **Point of View:** Where configuring a work agent stops being enough, and how MCP should carry identity and grants.
- **Selected Work:** Neuron, Tripkit (in progress), and production agents shipped at work.
- **Background:** Experience, skills, and education, kept below the fold.
- **Resume preview:** Formatted printable resume (`window.print()`) and raw text copy, as a secondary action.
- **Contact:** LinkedIn, X, GitHub, and email.

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

---

## Deployment

The app compiles to pure static HTML/CSS/JS in `dist/` and deploys from `main` to GitHub Pages.
